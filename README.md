# BMW M3 GTS — étude du V8

Une expérience web autonome pour explorer le V8 atmosphérique S65B44 de la
BMW M3 GTS E92. Elle utilise uniquement HTML, CSS et JavaScript, sans
dépendance applicative ni code giHabit.

## Lancer le site

Depuis ce dossier, exécutez :

```sh
npm start
```

Puis ouvrez [http://localhost:4173](http://localhost:4173). Python 3 est requis
pour le serveur statique.

## Explorer

- Modifiez l’accélérateur pour faire varier le régime et le mouvement du piston,
  de la bielle, des soupapes et du vilebrequin.
- Mettez l’animation en pause ou réinitialisez-la.
- Sélectionnez l’un des quatre temps pour lire son fonctionnement.
- Parcourez les fiches des principaux composants.

Le schéma animé ralentit la rotation pour rendre les temps observables ; il ne
constitue pas une simulation physique exacte. L’application respecte le réglage
de réduction des animations du navigateur.
